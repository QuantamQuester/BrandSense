# 📊 BrandSense — Brand Reputation & Sentiment Intelligence

Real NLP-powered brand reputation dashboard using **RoBERTa** to analyze
Amazon product reviews — not star ratings.

---

## 🗂️ Project Structure


## 🚀 How to Run (2 steps)

### Step 1 — Run RoBERTa sentiment scoring (ONE TIME)

```bash
# Samsung only — faster, good for testing (~5-10 min on CPU)
python run_sentiment.py --brand Samsung

# All brands (~30-40 min on CPU)
python run_sentiment.py
```

What this does:
- Downloads RoBERTa model (~500MB, first time only)
- Cleans all review text (removes HTML, URLs, duplicates)
- Runs RoBERTa on every review body (reads TEXT, not star ratings)
- Saves scored results to data/reviews_scored.csv

### Step 2 — Launch the dashboard

```bash
streamlit run app.py
```

Opens at http://localhost:8501

## 🧠 Sentiment Model

**Model:** `cardiffnlp/twitter-roberta-base-sentiment-latest`

- Fine-tuned RoBERTa on product reviews and social media text
- Returns: Positive / Neutral / Negative + confidence score (0-100%)
- Reads actual TEXT, not star ratings
- Handles sarcasm, negation ("not bad" = positive), emphasis (CAPS)
- 512 token limit — long reviews are automatically truncated
